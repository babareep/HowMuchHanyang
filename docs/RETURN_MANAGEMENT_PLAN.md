# 반납 관리 — 준비 브랜치

이 브랜치는 최신 main에서 생성됐으며 아직 반납 관리 기능 코드는 추가하지 않았습니다.
지도 PR과 독립된 출발점이며, 지도 병합 후 작업 시작 전에 최신 main을 반영하세요.

## 구현 범위

- 승인된 대여의 남은 일수, 오늘 반납, 기한 초과를 표시.
- 날짜 기준은 한국 시간, 종료일 다음 날부터 초과 1일로 계산.
- 완료된 요청은 더 이상 연체로 표시하지 않음.
- 초과수수료는 팀이 정한 1일 요율로 계산하는 안내 금액. 실제 결제·자동 청구 제외.
- 먼저 앱 내 안내로 구현. SMS/푸시/예약 발송은 별도 결정 없이 추가하지 않음.

## 작업 경계

- `src/features/returns/**`: 날짜·수수료 계산과 표시 컴포넌트.
- `tests/returns/**`: 한국 날짜 경계·당일·초과·반납 완료 검증.
- `/trades` 및 상품 상세에는 컴포넌트 호출만 최소 추가.
- 지도·상품 등록·채팅 파일은 수정하지 않음. 공통 타입 변경은 팀과 합의.

## 구현 전 확인

- 실제 `trade_requests`에서 반납 완료를 식별할 컬럼과 값 확인. 상품 상태만으로 요청별 반납을 추정하지 않음.
- 종료일 기준 시간과 초과수수료 요율 확정. 반납 당일 처리·이미 지난 데이터 처리 확인.
- 테이블·RLS·트리거를 확인한 후 DB 변경 필요성을 판단. 정의되지 않은 RPC를 먼저 호출하지 않음.
- A/B 테스트 및 main 빌드 성공 후 이 브랜치만 PR 생성. 상세 화면은 채팅 브랜치와 동시에 편집하지 않음.
