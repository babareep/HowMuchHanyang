# 본인 상품 수정

브랜치: `codex/item-edit`. 기준: 최신 origin/main `a4776b5`.

main에는 이미 `405e4b9`에서 본인 상품 수정 기능이 추가되어 있어 그대로 사용합니다.
이 브랜치에서는 수정 대상 상품/신규 등록 화면이 바뀌면 폼 상태를 새로 생성하고, 불러오기 실패를 안내하도록 보완했습니다.

## 확인 방법

1. 로그인 후 본인이 등록한 상품의 상세 페이지를 엽니다.
2. 작성자에게 표시되는 `수정` 버튼을 누르면 `/write?edit=상품ID`에서 기존 값이 로드됩니다.
3. 제목·설명·가격·판매/대여·기간·지도 위치·카카오톡 연락처·사진을 수정할 수 있습니다.
4. 새 사진을 고르지 않으면 기존 사진 URL을 유지합니다.
5. 수정 완료 시 기존 상품을 UPDATE하고 해당 상세 화면으로 돌아갑니다. 새 상품으로 INSERT하지 않습니다.
6. 다른 상품 수정이나 신규 등록으로 이동하면 이전 폼/미리보기 상태가 섞이지 않습니다.

## 권한과 범위

- 기존 코드의 작성자 ID 확인과 `id + seller_id` UPDATE 필터를 유지합니다.
- 실제 저장 권한은 기존 Supabase RLS에 따릅니다. DB·Storage 정책이나 컬럼은 변경하지 않았습니다.
- DB에서 수정이 차단되면 앱이 성공으로 표시하지 않습니다.
- 다른 사람의 상품 수정 요청 차단, 기존 값 로드·저장, 새로고침 유지 및 사진 교체는 시연 계정으로 확인하세요.
- 기존 거래 유형/가격/대여 기간 편집 정책은 main의 동작을 유지합니다. 거래 진행 중 편집 범위를 제한하려면 별도 팀 합의가 필요합니다.
- 실제 공유 상품을 자동 테스트로 수정하지 않았습니다.
